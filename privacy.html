Privacy Policy

This policy explains what data Lumen (the "bot") stores and why. Questions or deletion requests: [YOUR-EMAIL-HERE].

What the bot stores

The bot only stores data that its features need.

  • Server settings: IDs of channels and roles you choose, message texts you write (welcome message, ticket texts, custom commands), and your Premium status.
  • Member data per server: Discord user ID together with level and XP, message count, birthday (day and month only), reminders, votes in polls and suggestions, invite tracking (who invited whom) and submitted applications (the answers you type into an application form are stored so staff can review them; /forgetme deletes them).
  • Moderation records: warnings, moderation cases (action, reason, moderator ID, time), temporary bans, private moderator notes about users and ban appeals (the text a banned person writes to appeal). Servers need these for safety.
  • Server Coach statistics: daily counters per server (joins, leaves, messages, messages per channel and hour), the user IDs of members who wrote a message on a given day (kept for 35 days, to see who went quiet) and whether a new member wrote a message. Message content is never stored. Server admins can pause this in /coach.
  • Team data: for members with moderator permissions, a daily message count (kept for 100 days), away notices and handover notes that moderators write.
  • Tickets: a record of each ticket (channel, who opened it, type, status, time). When a ticket is closed, a transcript of the conversation is created as a file. It is posted into the server's own ticket log channel (if one is set) and sent by direct message to the person who opened the ticket. It is not kept in the bot's database. If a ticket has a question form, the answers are shown in the ticket channel. The record also keeps who handled the ticket, its priority, the time of the first reply and, if the member gives one, a 1-5 rating with an optional comment.

What the bot reads but does not store

  • Message text is processed in memory for AutoMod, XP, custom commands, and similar features. The bot does not keep a copy of normal chat messages. It only counts messages per member for the level system.
  • If a server enables logging, edited and deleted messages are posted by the bot into the log channel of that server.

AI features

When someone uses /ask, /summarize, /translate, the "Translate message" menu, or mentions the bot, the relevant message text is sent to an AI provider (Groq) to produce the answer. Do not send secrets or personal data to the AI. Short conversation context is kept in the bot's memory only and is lost when the bot restarts.

Web dashboard

If you log in to the dashboard, Discord shares your user ID, name, avatar and the list of your servers with the bot (scopes identify and guilds). This is kept in memory for up to 12 hours so you stay logged in. A cookie holds a random session ID. Nothing from your login is written to the database.

Third parties

Discord (platform), Groq (AI answers), top.gg (vote checks use your user ID), and Twitch/YouTube (the bot only requests public channel information, never your personal data).

Retention and deletion

  • If the bot is removed from a server, all data of that server is deleted after 30 days (Premium expiry is kept so a purchase is not lost). Re-adding the bot within 30 days cancels the deletion.
  • Members can delete their own data on a server with /forgetme. Moderation records and tickets stay on the server.
  • The bot makes a daily backup and keeps the last 7. Deleted data can remain in those backups for up to 7 more days.
  • You can also ask us to delete data: [YOUR-EMAIL-HERE].

Security and sharing

Data is stored on the operator's server. It is not sold and not shared with anyone except the providers listed above, and only as far as a feature needs it. No system is perfectly secure, but we limit access to the operator.

Children

Discord requires users to be at least 13 (or the minimum age in your country). The bot is not meant for younger users.

Changes

We may update this policy when features change. The current version is always on this page.
